# Hungnotes

A minimalist, raw markdown scratchpad and daily notes extension for VS Code.

## Features

- **Raw Markdown Editor**: Editor is the reader — no separate "read" mode, preview toggle, or rich-text abstraction. Clean, distraction-free markdown.
- **Auto-new document on launch**: Automatically opens with a new markdown document formatted with date templating (e.g. `YYYY-MM-DD.md` or `YYYY-DD-MM.md`).
- **Previous Docs Drawer**: One-click drawer list showing all previous notes (matching the clean right-aligned layout in the mockups). Click any document to switch to it instantly.
- **Seamless Auto-save**: Auto-saves as you type directly to disk — no save buttons or modals.
- **Dock Anywhere**: Place it in the Primary Activity Bar, Secondary Sidebar, or Bottom Panel (just like OpenChamber).
- **Native VS Code Theming**: Uses default VS Code tokens for sidebars, editors, borders, fonts, and lists, looking native in both light and dark themes.
- **Open in Editor Tab**: Click the focus/expand icon to open the note directly in VS Code's editor.

## Configuration

| Setting | Default | Description |
|---|---|---|
| `hungnotes.notesDirectory` | `""` (defaults to `~/.hungnotes`) | Custom directory path to store markdown notes |
| `hungnotes.dateFormat` | `"YYYY-MM-DD"` | Date format for new notes (`YYYY-MM-DD` or `YYYY-DD-MM`) |
| `hungnotes.defaultTemplate` | `"## raw notes\n\n"` | Default markdown template prepended to new notes |
