# VS Code and Zed Extensions

- **Fractalstyler VSCode** - Canonical Sass styles viewer and editor in the VS Code sidebar & panel.
- **Fractool React2Svelte** - Hacky React (TSX/JSX) components conversion to Svelte 5 with runes, with porting warnings, in the VS Code sidebar.
- **Hungnotes** - Minimalist raw markdown scratchpad and daily notes extension for VS Code.
- **OKLCH Lab** - Convert any colour between HEX, RGB(A), HSL(A) and OKLCH, and explore the OKLCH space with live gamut graphs.
- **Styles Intellisense** - Class and CSS-variable autocomplete with hover docs, built live from any Sass/SCSS/CSS folder you point it to.
- **Themer Studio** - Visually edit a VS Code color theme JSON, test colors live, and export installable themes.
